# Security Policy / 安全策略

## Reporting a vulnerability / 报告漏洞

Please report security vulnerabilities privately through the repository's Security page: [Security](https://github.com/wontonapp/wonton/security) → **Report a vulnerability**. Do not open a public issue.

请通过仓库 Security 页的 **Report a vulnerability** 私下报告安全问题，不要公开提 issue。

Please hold public disclosure until a fix is available. / 公开披露前请先给我们留出修复时间。

## Supported versions / 支持版本

Wonton is pre-1.0 (`0.x`). Only the latest version receives security fixes.

Wonton 处于 1.0 之前（`0.x`），只为最新版本修复安全问题。

## Response time / 回复时间

We will respond as soon as possible.

我们会尽快回复。
