# 目标与里程碑

## 总目标

做出一个能公开发行给普通用户、国内外都能用的 AI 原生家庭服务器 Wonton / 云吞。

用户在任意一台 Linux + Docker 主机上一行命令装好，用手机扫码配对后，就拥有一个住在自己家里、
随时能找到、能主动找你的私人 Agent。相册、文件、音乐、本地模型和任意 Docker 应用都以插件形式接入：
Agent 能调用它们，有网页的插件在 App 里像小程序一样使用。

以 M3（1.0 公开发布）为“完成”。每个里程碑都以下面的验收标准为准，没达到就不算完成。

## M0 技术验证

在写大量功能之前，先证明主干链路（iroh 隧道、Matrix、加密推送、默认 Bot、厚核心、插件安装和小程序）在真实网络和
真实手机上可行。结论见各 ADR 的“验证结果”。iOS 推送要付费的 Apple 开发者账号，自建节点推迟，两件都归到 M2。

## M1 MVP 内测

按用户路径验收，通过 TestFlight 和直装 APK 分发：

1. 在干净的 Debian 或 Ubuntu + Docker 主机上（amd64 和 arm64 各一台）执行一行安装命令，10 分钟内
   装完；浏览器打开局域网页面，能看到配对二维码和运行状态。
2. iOS / Android App 扫码配对成为主人；手机切到蜂窝网络后仍可正常使用。
3. 在“模型设置”小程序（magpie）里填入任意 provider 的 key 后，默认 Bot 能收发文字、图片和文件。
4. 插件商店：官方目录至少包含 Immich、Navidrome、Paperless-ngx、Ollama、Syncthing、Samba，热门应用
   转成官方插件，不做 CasaOS 导入；安装前展示并确认权限；插件网页在 App 内打开，支持 OIDC 的应用自动登录。
5. 对 Bot 说“帮我装某个应用”，Bot 在聊天里发确认按钮，主人确认后完成安装并回报结果。
6. Bot 能在已授权的文件夹里查找文件，并通过 MCP 在 Immich 里按内容搜照片。
7. 核心在 App 里一键升级；健康检查失败时自动回滚到旧版本。
8. 工程：CI 门禁全绿；核心行为测试覆盖配对、聊天、推送、插件安装的主流程；端到端冒烟脚本能在
   真实主机上复跑。
9. 第三方 App 连回家：手机不装证书、不开 VPN，主人在 App 里打开入口后，用 Immich 官方 App 经局域网直连和主人
   自己的域名各备份一张照片（ADR-0021）。我们运营的云端部分在 M2 第 13 项。
10. 插件页进底栏：插件网页能固定到底栏、能全屏，主题跟着 App（ADR-0033）。
11. Agent 写插件：在聊天里对 Bot 说一句需求，Bot 写出插件，主人确认后装好、固定到底栏，页面能用（ADR-0033）。
12. 新用户引导：配对后选 Agent、接模型、按需求选应用，最后一起提交，应用在后台自动装；每一步都能跳过；改 Agent 名单和推荐清单不用发 App（ADR-0034）。
13. 帮助：问 Agent “怎么加一台设备”，它查文档答对；主机连不上 GitHub 时也能答，文档更新后答的是新内容（ADR-0034）。

ACP 桥和 Codex、Claude Code、omp 的插件和 M1 同时开工，M1 验收不等它们（ADR-0034）。

MVP 只做主干。M2 的能力在架构上预留接口，MVP 期间就可以由多个 Agent 在各自的 worktree 里
并行开发，测完提 PR 合并。

## M2 第一个大版本

1. **实时通话**：和 Bot 语音通话，App 在后台也不断线；通话中可以把屏幕共享给 Agent。先做云端
   实时模型直连，再做家里 LiveKit 的隐私模式。
2. **插件网页里的音频**：Navidrome 这类插件的网页在 App 里放音乐，切到后台、锁屏后继续放，锁屏和控制中心有曲名、封面和控制，来电和插拔耳机时暂停。
   Wonton 是插件的容器，不做原生音乐页：播放体验交给插件自己的网页，底座把插件网页适配好（主人 2026-11-06 定）。
3. **桌面端**：Compose Multiplatform，覆盖 Windows、macOS、Linux。
4. **家人邀请**：每人有私人 Bot 和私人空间；主人可以建共享 Bot，拉进家庭群。
5. **ACP 桥**：可以把 Codex、Claude Code、omp 等装成新的 Bot，引导的选择页上选得到（ADR-0034）。
6. **Bot 之间互发消息（同机）**：联系人审批，频率和转发跳数限制。
7. **第三方 IM 渠道插件**：Telegram、飞书、企业微信等。
8. **U 盘自动导入插件**：优先选现成开源方案，先不做。不另做文件语义检索插件：Agent 经各应用自带的检索去找（如 Immich 按内容搜照片）。
9. **国内 Android 厂商推送**：依赖公司主体和商店上架。
10. **插件页的原生能力**：选文件、分享，按 ADR-0033 的桥扩展。
11. **自建中继与发现节点**：香港、海外各一台主机部署 iroh-relay、iroh-dns-server，
    客户端从签名的节点列表获取地址；内测中经公共中继体验差就提前做。
12. **系统推送**：App 被杀或锁屏时，Bot 的回复和插件通知以系统推送弹出（渠道见 ADR-0003）；推送中继看不到明文，
    部署在我们的一台公网主机上。推送的接口保留，M1 不以它验收。
13. **第三方 App 入口的云端部分**：公网中继、家名服务、DNS 和证书服务（ADR-0021），和第 11、12 项一起部署。

## M3 公开发布 1.0

1. 国内外应用商店上架：公司主体、App 备案、商标检索与注册、隐私政策。
2. 备案完成后增加内地中继与推送节点。
3. 插件规范 1.0 和插件开发文档公开。
4. Web 端：同一套 Compose UI 编译到 Web，核心在服务器上运行，浏览器经 WebSocket 连接。
5. 跨机 Bot 通信插件（Matrix 联邦走 iroh，或 A2A）。
6. 安全审查：Agent 权限、插件权限、配对与推送链路。
7. **第三方 App 入口开放注册**：前置条件见 ADR-0021 的“防滥用和 PSL”。PSL 申请至少提前半年提交：合并加浏览器发版要好几个月，
   还要求域名剩余注册期在两年以上。
8. **Agent 的账号登录**：经 ACP 桥用 Claude 订阅不等 Anthropic 书面确认，公开版本照常提供（ADR-0034）。
