# 目标与里程碑

## 总目标

做出一个能公开发行给普通用户、国内外都能用的 AI 原生家庭服务器 Wonton / 云吞。

用户在任意一台 Linux + Docker 主机（Mac、Windows 上是云吞自带的 Linux 虚拟机）上一行命令装好，用手机扫码配对后，就拥有一个住在自己家里、
随时能找到、能主动找你的私人 Agent。相册、文件、音乐、本地模型和任意 Docker 应用都以插件形式接入：
Agent 能调用它们，有网页的插件在 App 里像小程序一样使用。

一户一个枢纽在家里，其他电脑作为受管设备挂在枢纽下；每人默认一个主 Agent，可自建多个 profile。

默认助手只用 Hermes，保留家人各自的主 Agent 和多个 profile；OpenClaw 只作替换备选，不并行维护多内核。模型沿用 Hermes 自带供应商接入，Magpie 是普通可选插件，核心和默认装机不依赖它。边界见 [ADR-0108](adr/0108-hermes-default-kernel.md)。

以 M3（1.0 公开发布）为“完成”。每个里程碑都以下面的验收标准为准，没达到就不算完成。

## M0 技术验证

在写大量功能之前，先证明主干链路（iroh 隧道、Matrix、加密推送、默认 Bot、厚核心、插件安装和小程序）在真实网络和
真实手机上可行。结论见各 ADR 的“验证结果”。iOS 推送要付费的 Apple 开发者账号，自建节点推迟，两件都归到 M2。

## M1 MVP 内测

按用户路径验收，通过 TestFlight 和直装 APK 分发：

1. 在干净的 Debian 或 Ubuntu + Docker 主机上（amd64 和 arm64 各一台）执行一行安装命令，10 分钟内
   装完；浏览器打开局域网页面，能看到配对二维码和运行状态。
2. iOS / Android App 扫码配对成为主人；手机切到蜂窝网络后仍可正常使用。
3. 使用 Hermes 自带的供应商接入，以其支持的 API key 或订阅登录接好模型后，默认主 Agent 能收发文字、图片和文件（ADR-0118 起房间不加密），能开辅助对话、另建 profile；不安装 Magpie 也能完成这条链路（ADR-0108）。
4. 插件商店：官方目录至少包含 Immich、Navidrome、Paperless-ngx、Ollama、Syncthing、Samba，热门应用
   转成官方插件，不做 CasaOS 导入；安装前展示并确认权限；插件网页在 App 内打开，支持 OIDC 的应用自动登录。
5. 对 Bot 说“帮我装某个应用”，Bot 在聊天里发确认按钮，主人确认后完成安装并回报结果。
6. Bot 能在已授权的文件夹里查找文件，并通过 MCP 在 Immich 里按内容搜照片。
7. 核心在 App 里一键升级；健康检查失败时自动回滚到旧版本。
8. 工程：CI 门禁全绿；核心行为测试覆盖配对、聊天、推送、插件安装的主流程；端到端冒烟脚本能在
   真实主机上复跑。
9. 第三方 App 连回家：手机不装证书、不开 VPN，主人在 App 里打开入口后，用 Immich 官方 App 经局域网直连和主人
   自己的域名各备份一张照片（ADR-0021）。自己的域名在 App 里配，预设 deSEC（ADR-0089）；公网入口经主人的路由器转发、自己的服务器或
   Cloudflare Tunnel，默认关，有总开关（ADR-0090）。我们运营的云端部分在 M2 第 13 项。
10. 应用的入口有两条：底栏上的应用，和侧边栏“我的应用”里的应用（底栏默认 Agent、应用两项，可增删排序）；应用整页打开、左边缘返回（ADR-0095、ADR-0126）。
11. Agent 写插件：在聊天里对 Bot 说一句需求，Bot 写出插件，主人确认后装好、加到 底栏，页面能用（ADR-0033、ADR-0126）。
12. 新用户引导：默认使用 Hermes，不要求选择内核；能完成所需资料、模型接入与应用安装，未配置、失败和可用如实区分，不以 Magpie 为前置。引导与模型设置的具体交互另行设计，不沿用各家内核选择或固定 Magpie 页面的要求（ADR-0108）；应用安装权限和帮助文档沿用 ADR-0034。
13. 帮助：问 Agent “怎么加一台设备”，它查文档答对；主机连不上 GitHub 时也能答，文档更新后答的是新内容（ADR-0034）。

不再把 ACP 桥、各家 Agent 插件和第二批内核接入列为交付目标；调用其他 Agent 采用 Hermes 原生 ACP 委派，家人的主 Agent 和多个 profile 不在裁剪范围（ADR-0108）。

MVP 只做主干。M2 的能力在架构上预留接口，MVP 期间就可以由多个 Agent 在各自的 worktree 里
并行开发，测完提 PR 合并。

## 下一批能力的验收

复用 Hermes 的既有能力，不另建核心任务或记忆引擎。三项均用真实输入、拒绝/取消和重启恢复验收；只定义能力与验收，不在此固定 App 的入口或布局（ADR-0108）。

| 能力 | 验收结果 |
| --- | --- |
| 任务 | 能辨认手上的活和等我的事；拒绝、取消真实生效，重启后如实恢复工作与等待状态。 |
| 透明记忆 | 归属人能查看、修改、删除记忆，并从后续真实回答核对效果；拒绝或取消不修改，重启后保留结果，不越过私人/共享 Bot 数据边界。 |
| 晨报与提醒 | 一句话订阅，真实按时送达正确的人；拒绝、取消后不再投递，重启后仍符合订阅与执行结果，主动发送继续遵守核心确认和主人自动放行范围。 |

## M2 第一个大版本

1. **实时通话**：和 Bot 语音通话，App 在后台也不断线；通话中可以把屏幕共享给 Agent。先做云端
   实时模型直连，再做家里 LiveKit 的隐私模式。
2. **插件网页里的音频**：Navidrome 这类插件的网页在 App 里放音乐，切到后台、锁屏后继续放，锁屏和控制中心有曲名、封面和控制，来电和插拔耳机时暂停。
   Wonton 是插件的容器，不做原生音乐页：播放体验交给插件自己的网页，底座把插件网页适配好（主人 2026-11-06 定）。
3. **桌面端**：渲染层统一 React；PWA 第一期先做（M2 内部预览），Electron 随后三平台一起；桌面端还带本机服务供手机远程控制（ADR-0124）。
4. **家人邀请**：每人有私人 Bot 和私人空间；主人可以建共享 Bot，拉进家庭群。
5. **原生 ACP 委派**：Hermes 能调用 Codex、Claude Code 等上游 Agent，真实结果、拒绝/取消及重启后的状态可核对；不依赖 Wonton ACP 桥，不把被委派程序冒充为独立 Wonton Bot（ADR-0108）。
6. **Bot 之间互发消息（同机）**：联系人审批，频率和转发跳数限制。
7. **第三方 IM 渠道插件**：Telegram、飞书、企业微信等。
8. **U 盘自动导入插件**：优先选现成开源方案，先不做。不另做文件语义检索插件：Agent 经各应用自带的检索去找（如 Immich 按内容搜照片）。
9. **国内 Android 厂商推送**：依赖公司主体和商店上架。
10. **插件页的原生能力**：选文件、分享，按 ADR-0033 的桥扩展。
11. **自建中继与发现节点**：香港、海外各一台主机部署 iroh-relay、iroh-dns-server，
    客户端从签名的节点列表获取地址；内测中经公共中继体验差就提前做。
12. **系统推送**：App 被杀或锁屏时，Bot 的回复和插件通知以系统推送弹出（渠道见 ADR-0003）；推送中继看不到明文，
    部署在我们的一台公网主机上。推送的接口保留，M1 不以它验收。
13. **第三方 App 入口的云端部分**：公网中继、家名服务、DNS 和证书服务（ADR-0021），和第 11、12 项一起部署。
14. **系统入口**：桌面小组件（最近聊天、Bot 状态、问 Bot）、系统搜索里的会话、iOS 控制中心和锁屏的按钮，点了直接进 App 的那一处（ADR-0100）。
15. **受管设备**：一户一个枢纽，其他电脑作为受管设备挂在下面；主 Agent 决定把任务派到哪台设备，不每次问用户；设备上跑 herdr 和守护进程，经 iroh 隧道接；权限请求进收件箱（允许一次、总是允许、拒绝、拒绝并说明，超时自动拒）；设备离线排队、过期作废并通知；监工和会话在枢纽上；目标机 Agent 用自己的工作区。
16. **网络如实降级**：设备或枢纽访问海外站点不通时静默降级，设置里如实标出哪几项慢或不可用。

## M3 公开发布 1.0

1. 国内外应用商店上架：公司主体、App 备案、商标检索与注册、隐私政策。
2. 备案完成后增加内地中继与推送节点。
3. 插件规范 1.0 和插件开发文档公开。
4. **Web 端（1.0 正式）**：PWA 用同一套 React 渲染层，每个用户一份核心、所有窗口共用；浏览器经中继用 WSS，中继按用户限流（细节见 ADR-0124）。以后可用 WebRTC 打洞。
5. 跨机 Bot 通信插件（Matrix 联邦走 iroh，或 A2A）。
6. 安全审查：Agent 权限、插件权限、配对与推送链路。
7. **第三方 App 入口开放注册**：前置条件见 ADR-0021 的“防滥用和 PSL”。PSL 申请至少提前半年提交：合并加浏览器发版要好几个月，
   还要求域名剩余注册期在两年以上。
8. **模型与订阅登录**：按发布所选 Hermes 版本原生支持的供应商和登录方式验收；不承诺所有订阅可用，不沿用经 ACP 桥登录各家账号的产品路径，也不为此另建登录适配（ADR-0108）。
