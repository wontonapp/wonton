# ADR-0060 聊天页的显示方式：气泡或文档，核心合成，壳只画预设

- 状态：已接受（2026-11-07）

## 背景

主人要聊天页可以自定义：即时消息的气泡可以，按 Markdown 排版的文档也可以。

核心已经把 Bot 的消息按 Markdown 排成块（`wonton-client/src/chat/rich.rs`），壳只画块。缺的是排版形态：
不论长短都装进气泡，Agent 的长回答在气泡里又窄又挤，表格和代码块只能在气泡里横向滚。

云吞的聊天是一个即时通讯，像 Telegram、微信那样接入各种 Agent。Agent 自己的网页是另一种用法，走插件已有的页面，
不是聊天页的一种形态（主人 2026-11-07）。

## 决策

### 两种形态

| 形态 | 怎么画 | 默认给谁 |
|---|---|---|
| 气泡（`bubbles`） | 即时消息的气泡 | 家人、群聊、和人的私聊，以及没声明形态的 Bot |
| 文档（`document`） | 别人的消息不装气泡、铺满宽度，像读文章；自己的话仍是气泡，分得清谁说的 | Agent 插件的 Bot |

一个房间一种形态。和某个 Bot 的私聊按这个 Bot 的设置，其余房间按全局默认。

### 可调项只给预设

除形态外，第一版只开放两项：字号（在 App 的字号上小一级、标准、大一级）和代码块、表格放不下时横向滚动还是折行。
不做自由调色、自定义字体、上传样式：组合一多，每种都要在两端、深浅色、读屏、大字号下验一遍，验不过来。
密度、时间这类跟着形态走，以后要开放再加枚举。

### 分层

- 客户端核心把插件声明的默认值、用户的选择合成每个房间的 `ChatLayout`（`RoomRow.layout`），壳照着画，不自己合并。
- 每个字段按用户对这个 Bot 的选择、插件声明、全局默认、内置默认的顺序合成；插件只声明形态，字号与代码溢出跟随用户选择和全局默认。
- 未声明形态的 Bot 由服务器给出 `bubbles`，与声明气泡一样优先于全局形态；账号数据中不认识的取值不参与合成，回到这个字段的默认值。
- 房间是否属于插件 Bot 以已装列表为准；列表移除后，账号数据里残留的 Bot 选择不作用于该私聊。
- 插件只能在清单里选形态，带不进样式、CSS 或代码。
- 枚举都有 `Other`：新核心配旧 App 时按气泡、标准字号、横向滚动画。

### 插件怎么声明

在已有的 `x-wonton.bot` 段里写 `chat_layout: document`（`bubbles` 或 `document`，不写是 `bubbles`）。
家里的服务器随插件列表给出 `InstalledPlugin.chat`。

### 选择存在哪

Matrix 全局账号数据 `app.wonton.chat_layout`：

```json
{"default": {"form": "bubbles"}, "bots": {"@codex:home.example": {"form": "document", "code": "wrap"}}}
```

- 跟着账号走，换手机、多设备都一样；服务器上只有主人自己读得到。
- 只存用户改过的项：插件以后改了默认值，没动过的用户自动跟上。
- 改一项只改原始 JSON 里的那一处，其余原样写回：旧 App 把不认识的取值读成 `Other`，整份重写会冲掉新 App 存的值。
- 修改同一份选择中的其他字段时，带回的 `Other` 表示保留服务器上的原值；`None` 才删除对应字段，恢复继承。
- 写失败进 `ChatViewModel.problem`，显示方式不变，不假装已经生效。

### 从聊天进插件的网页

Bot 所属的插件有网页（`webui`）时，和这个 Bot 的聊天顶栏菜单和 Bot 资料页上有一项“打开 <插件名>”，在插件页的容器（ADR-0033）里
打开它的网页，和从应用页打开一样。壳按 `BotView.plugin_id` 找到插件的 `web_url`，不用新字段。一个插件多个 Bot 时，
每个 Bot 各自的网页入口跟 #683 走。

## 考虑过的做法

- **只给气泡**：Agent 的长回答、表格、代码在气泡里难读，主人否了。
- **把 Agent 自己的网页做成聊天页的第三种形态**：先这样设计过，主人否了：聊天就是即时通讯，网页是插件的另一种用法，
  两者都在，不互相替代。
- **插件带自己的样式或渲染代码进 App**：设计系统、读屏、深浅色都管不住，App Store 也会有下载代码的疑问；
  要自己界面的 Agent 用它的网页。
- **选择存本机**：换手机就没了，多设备不一致。

## 代价

- 两端各多一种时间线行（文档），测试和截图翻倍。
