# ADR-0065 链接预览由家里的核心去取，发送时附进消息

- 状态：已接受（2026-11-08）

## 背景

主人要聊天里的链接带预览卡片（标题、摘要、大图），点开在 App 里看。预览得有人去对方网站取网页和图片。谁去取，决定了三件事：

- 别人发来的链接会不会暴露主人手机的 IP 和所在地；
- 国内手机打不开的外网站，预览能不能取到；
- 会不会给 Bot 开一条经 homeserver 出网的路。

Matrix 的做法有两种：客户端调 homeserver 的 `preview_url`，或者发送方按 [MSC4095](https://github.com/matrix-org/matrix-spec-proposals/pull/4095)（bundled URL previews）把预览附进消息事件。
Tuwunel 的 `preview_url` 我们故意关着（ADR-0003）：Bot 也有 Matrix 令牌，开了就等于让 Bot 经 homeserver 任意出网，`egress` 一组测试守着这一条。

## 决策

### 1. 核心取预览，只给这台服务器上的人的设备用

- 核心加一个网关接口：给一个 http(s) 网址，回标题、摘要、站点名、图片（经核心转出的地址）和最终网址。主人和家人的设备都能调；
  Bot 和插件拿不到（不经 MCP 总线、不进插件网络）。家人看聊天一样需要卡片，要挡的是能自己发请求的 Bot 和插件。
- 按设备限速防刷（每台设备每分钟 30 次，按实测调），超了回“请求太频繁”。
- 出网走主人配的出网代理（ADR-0023），没配就直连，和插件出网同一条路。
- **配了代理时经代理用 DoH 解析域名**：本地 DNS 在国内可能回一个公网假地址，经代理 `CONNECT` 它也连不上。核心向可配置的
  DoH 服务器发 RFC 8484 请求（A 和 AAAA）。服务器写在出网代理的设置里：`WONTON_DOH_URL` 环境变量或设置文件的 `doh_url`，
  默认 `https://1.1.1.1/dns-query`（用 IP，不需要先解析它自己的域名）。
  DoH 服务器连不上、回错误、找不到域名都算解析失败，报单独的类别，**不退回本地解析**，也不混进“对方站点出错”。
  没有 DoH 结果就没有可检查的地址，宁可失败也不拿本地假地址去连。
- **拒绝内网和本机地址**：核心先自己解析域名（配了代理时用的是经代理拿到的 DoH 结果），解析出的任何一个地址是回环、私有、链路本地、CGNAT、ULA、组播或未指定地址就拒绝；
  再用解析出的 IP 去连（经代理时用 `CONNECT <ip>:<port>`，TLS 的 SNI 和 `Host` 仍是原域名），防止解析和连接之间换了地址。
  跳转最多 3 次，每一跳都重新检查。只允许 80、443 和 8080、8443 端口。
  插件资源的取法（`files/resource.rs`）是另一种防护：它只认插件服务名、不出内网之外，这里不复用它，只复用它限大小、限时的读法。
- 限制：网页只读前 512 KiB、找 `<head>` 里的 Open Graph、Twitter Card 和 `<title>`、`<meta name=description>`；图片只取 `og:image`，不超过 5 MiB，
  只认常见图片类型；整次 10 秒超时。取不到就如实回错误类别（对方站点出错、超时、被拒绝的地址、不是网页），不回空卡片。
- 结果按网址缓存 24 小时（失败缓存 10 分钟），存核心数据目录，图片一起缓存。

### 2. 发送时附进消息（MSC4095）

- 发送框里打出链接，客户端核心向自己的核心取预览，显示在发送框上方，可以点叉去掉。发送时把预览按 MSC4095 写进事件
  （未定稿前用它的 unstable 字段 `com.beeper.linkpreviews`）：图片由手机上传到 homeserver 的媒体库，加密房间按加密附件上传。
- 收到的消息带了预览就直接用，不再去取；没带（别的客户端、旧版本）再向自己的核心取。
- 每条消息只给第一个链接出卡片。

### 3. 点链接怎么开

链接的类别由客户端核心判断，壳只按类别开：外部 http(s)（iOS 的 SFSafariViewController、Android 的 Custom Tabs）、插件地址（进插件页，走隧道）、
Matrix 链接（matrix.to、房间、用户，在 App 内跳转）、邮件和电话（交给系统）。认不出的类别落到 `Other`，按外部链接开。

## 考虑过的做法

- **开 Tuwunel 的 `preview_url`**：标准做法，Element 等客户端直接能用；但 Bot 的令牌也能调，等于给 Bot 开了经 homeserver 出网的口子，和 ADR-0003 冲突。
- **手机自己取**：最简单，但别人发来的链接会让主人的手机直接连对方网站，暴露 IP 和所在地；国内手机取不到很多外网站；还费电。
- **只靠发送方附预览**：别的客户端、Bot 发的消息多半不带，收到的链接大部分没卡片。

## 代价与待验证项

- 收到的链接核心都会自动去取，对方网站看到的是家里服务器的出口地址（经代理时是代理的）。接受这一点：联邦关着（ADR-0003），
  能发消息进来的只有家人、好友和 Bot，没有陌生人，不另设“只给谁取”的开关。
- 发送方附的预览是对方说了算，可能和网页实际内容不一样；卡片上显示最终网址的域名，点开以实际网页为准。
- 国内被墙的域名，本地 DNS 回的是假公网地址，经代理也连不上，这是配了代理也要走 DoH 的原因。代价是每个域名多一次经代理的
  DoH 请求，DoH 服务器不可用时预览直接报解析失败；主人换一个能用的 DoH 服务器解决。
- MSC4095 还没定稿，字段名可能会改，跟着改。
- 预览图片经核心转出，占家里服务器的流量和磁盘（有缓存上限，按实测定）。
