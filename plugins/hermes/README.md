# Hermes

## 初始配置

显式关闭 `sessions.auto_prune`：保持上游不自动清理会话的默认行为，也不在主人配对前发送低磁盘询问。
初始配置只在空数据目录中写入，不覆盖已有配置；这项设置不恢复历史消息的密钥。
