# App 图标与启动屏

两处都用主人 2026-11-21 画的浅天蓝毛绒云原图：`mascot/cutout.png` 是从原图抠出的角色，形状、角度、神态都不改，只缩放、居中。
App 图标把角色放在蓝到白的渐变底上；启动屏只放角色本身，底色是米白和深色。

- `mascot/cutout.png`：唯一源图，不动。
- 脚本按角色的有效区居中、缩放：iOS 出浅色、深色、着色三套小尺寸，同像素的槽位共用一份（60@2x 就是 40@3x），
  1024 商店图只出浅色一份；Android 出自适应图标的前景、背景、单色，另有两端的启动画面。深色版压深底色，
  着色版压成中灰并出灰度图，Android 的单色层和通知图标是白色剪影。

角色是主人自己画的，没有上游素材，使用随主仓库。

改完运行 `python3 scripts/make-app-icon.py`（要 Pillow，HPND 许可，`python3 -m pip install -U Pillow`），先验源图再生成，
每张成品也验尺寸、透明通道和明暗差，不合格就停。生成结果一起提交；缩放算法随 Pillow 版本有小差异，CI 不比对生成结果，只编 App。

iOS 模拟器会缓存启动屏，看新启动屏要先卸载 App。
